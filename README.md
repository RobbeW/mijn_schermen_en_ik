# Mijn schermen en ik

Dit project bevat een volledige lesreeks Mediawijsheid voor de eerste graad secundair, opgebouwd uit 4 gekoppelde webopdrachten met een centrale startpagina.

## Startpunt

Open de startpagina:

- `index.html`

Van daaruit navigeer je naar alle onderdelen via de overzichtskaarten of het hamburgermenu links.

## Projectstructuur

- `index.html`  
  Landing- en oriëntatiepagina van de lesreeks.
- `imec_reflectiedashboard/imec.html`  
  Reflectiedashboard met imec-context.
- `mijn_schermen_en_ik_video_prevragen/index.html`  
  Video-opdracht met segmentvragen en reflectie.
- `mijn_schermen_en_ik_vrt_leesopdracht/index.html`  
  Leesopdracht met begrip, transfer, woordenlijst en samenvatting.
- `posteropdracht_schermtijd_acties/index.html`  
  Slotopdracht: acties uitwerken en posterplan voorbereiden.

## Aanbevolen volgorde in de les

1. imec reflectiedashboard  
2. video-opdracht  
3. leesopdracht  
4. posteropdracht


## Technische notities

- Alle pagina’s zijn single-file HTML (inline CSS en JavaScript).
- Navigatie tussen pagina’s is projectbreed op elkaar afgestemd.
- Elke pagina bevat links via een gedeeld hamburgermenu linksboven.
